INTEGRATION REFERENCE

Two paths to an evaluation

Use the UI for guided submission or call the FastAPI endpoints directly.

01 / METRICS

POST /evaluate

Send a model name, task type, at least one compatible metric, and optional experiment metadata.

{
  "task_type": "classification",
  "model_name": "RandomForestClassifier",
  "metrics": {"accuracy": 0.91}
}

02 / ARTIFACTS

POST /evaluate-from-data

Send multipart model_file, test_dataset_file, and JSON-encoded metadata.

metadata = {
  "task_type": "regression",
  "target_column": "Price",
  "model_name": "Linear Regression",
  "framework": "sklearn"
}

RESPONSE

EvaluationResponse fields

statusmessagereport_idevaluation_sourcemodel_nametask_typesummaryrisk_leveldeployment_readiness

The detailed narrative is returned in summary. Internal processed metrics, metric flags, and recommendations are not separate response fields.
